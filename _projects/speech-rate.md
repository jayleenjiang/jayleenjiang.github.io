This project investigates how distal speech rate shapes word segmentation. The codebase includes ERP analysis scripts, particle-filter model code, selected figures, and paper materials.

Main components:

- Analysis of 128-channel EEG/ERP data from 21 participants.
- Semi-Markov particle-filter model with rate-dependent duration priors.
- Model-to-ERP comparison for early responses to reduced function words.

The project connects computational predictions with neural evidence, giving a mechanistic account of how listeners adapt to changing speech rates.
